# Солнечные электростанции для бизнеса

Источник: https://energytool.mts.ru/solar-panels

EnergyTool предлагает солнечные электростанции (СЭС) для бизнеса по модели «под ключ»: оборудование, строительно-монтажные и пусконаладочные работы.

## Ориентиры по мощности

- Малый бизнес: СЭС мощностью 10–50 кВт. Для небольшого кафе установка мощностью 15–20 кВт может покрыть 50–70% потребления.
- Средний бизнес: СЭС мощностью 50–500 кВт. Для среднего производственного предприятия установка мощностью 200–300 кВт может покрыть 30–50% потребления.

Фактические мощность, экономия, стоимость и условия зависят от объекта и рассчитываются менеджером.
