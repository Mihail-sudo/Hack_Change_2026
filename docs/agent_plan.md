# План разработки агента

План обновлён после первого чекпоинта и по материалам из `kimi_code_docs/`. Источники правды: официальная база с Google Drive, технический регламент сабмита и `docs/contract.md` для стыков команды.

Статусы: ⬜ не начат · 🟨 в работе · ✅ готово. Не отмечаем этап готовым без выполнения его критериев.

## Зафиксированные условия

- Официальная база: `data/knowledge-base/**/*.md`; материалы сайта больше не используются.
- Генеративная модель: `qwen/qwen3.8-27b`. Локально используется Polza, на платформе — API организаторов.
- Качество ответов на чекпоинте признано хорошим; изменения проверяем на регрессии.
- Целевое время ответа интерактивного агента — менее 8 секунд; текущий ориентир на чекпоинте — 5,2 секунды.
- Интерфейс одобрен без изменений. Новые функции интерфейса не планируем, нужна только корректная интеграция.
- Для автоматической проверки нужен пакетный `solution.py`: `questions.csv` → `submission.csv`. Это не интерактивный `cli.py`.
- На платформе нет своих ключей и данных в ZIP: API и входные файлы предоставляет окружение.
